* sliders
The outer circle is always the size of the window \( R = \frac{SIZ}{2} \). By default,
#+BEGIN_SRC c
#define SIZ 600
#+END_SRC
this value is used for window size.

Sliders control (in order):
- the radius of the inner circle (\( r \))
- the radius of the point (\(P\)) on the inner circle (\( r' \))
- the quality (step size - lower is better)
- the number of rotations (higher is better)
